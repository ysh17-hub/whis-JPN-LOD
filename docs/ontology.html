用語値説明
whis:HeritageIrrigationStructureクラス世界かんがい施設遺産に登録された施設。schema:LandmarksOrHistoricalBuildings のサブクラス。
whis:registeredYearxsd:gYearICID（国際かんがい排水委員会）による登録年。
whis:builtYearxsd:gYear建設年。着工・完成・供用開始のどれかは builtYearBasis に書く。
whis:builtYearBasis文字列builtYear の根拠（着工・完成・供用開始・資料記載年など）。
whis:builtPeriod文字列建設時期。資料に西暦の年がない施設について、資料の表現のまま記録したもの（例：「およそ400年前に建設」「4世紀前半に築造」）。年への換算はしていない。builtYear がある施設には使わない。
whis:facilityType文字列施設の種類（水路・ため池・堰・用水群・揚水機場）。農林水産省が示す対象施設の例（ダム、ため池などの貯水施設、堰・分水施設、水路など）を参考に作成者が分類した。
whis:waterSourceWikidataの項目（なければ文字列）水源の川・湖など。Wikidata に同じ川・湖の項目があるときは、その IRI で示す（複数あり得る）。
whis:waterSourceName文字列水源の名前を資料の表記のまま記録したもの（例：奥入瀬川（十和田湖））。
whis:prefectureCode文字列都道府県コード（ISO 3166-2:JP 形式、例: JP-04）。
whis:irrigatedAreaxsd:decimalかんがい面積（ha）。資料によって値が異なるものは空欄にし、comment に両方を書いた。
whis:managedBy文字列管理者（土地改良区など）。
whis:representativePoint文字列座標を取った代表地点の名前（取水口・堰・池など）。
whis:facilityCategorySKOS の概念施設の種類を、下の「施設の種類（SKOS）」の概念で表したもの。国連食糧農業機関（FAO）の多言語シソーラス AGROVOC と Wikidata のクラスにつながる。
whis:pointElevation数値（m）代表地点の標高（東京湾平均海面からの高さ）。国土地理院の標高タイル（地理院タイル）で、細かいものから順に 1mメッシュ（DEM1A）→5mメッシュ（DEM5A→DEM5B→DEM5C）→10mメッシュ（DEM10B）の値を使った（地理院地図の標高表示と同じ順）。池や川の上の点は水面の高さになる。目安の値。
whis:pointAddressAreaIRI（住所LOD）代表地点がある大字・町丁目を表す、住所LOD（Linked Open Addresses Japan）の IRI。住所LODに大字の項目がないときは市区町村の IRI。
whis:pointMunicipalityIRI（統計LOD）代表地点がある市区町村を表す、統計LOD（政府統計の総合窓口 e-Stat）の標準地域コードの IRI。人口などの統計とつなげられる。
whis:pointElevationSource文字列標高を求めた数値標高モデルの種類（DEM1A＝航空レーザ測量の1mメッシュ、DEM5A＝5mメッシュ、DEM10B＝10mメッシュ など）。
whis:pointAddress文字列代表地点の座標がある場所の住所（市区町村・大字）。国土地理院の逆ジオコーダで座標から求めた。川の上の堰などは、隣の市町村になることがある。

施設の種類（SKOS）

農林水産省が示す世界かんがい施設遺産の対象施設の例（ダム、ため池などの貯水施設、堰・分水施設、水路など）を参考に作成者が分類し、 国連食糧農業機関（FAO）の多言語シソーラス AGROVOC と Wikidata のクラスに結びました（2026-11-23 確認）。 意味の範囲が完全に同じとは言えないものは skos:closeMatch、相手のほうが広いものは skos:broadMatch です。
