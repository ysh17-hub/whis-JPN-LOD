地図Turtle

独自語彙 whis:

名前空間: https://ysh17-hub.github.io/whis-lod/ontology#
既存の語彙（schema.org、GeoSPARQL、W3C Basic Geo、DCMI Terms、DCAT、OWL）で表せない項目だけを定義しています。

用語値説明
whis:HeritageIrrigationStructureクラス世界かんがい施設遺産に登録された施設。schema:LandmarksOrHistoricalBuildings のサブクラス。
whis:registeredYearxsd:gYearICID（国際かんがい排水委員会）による登録年。
whis:builtYearxsd:gYear建設年。着工・完成・供用開始のどれかは builtYearBasis に書く。
whis:builtYearBasis文字列builtYear の根拠（着工・完成・供用開始・資料記載年など）。
whis:facilityType文字列施設の種類（水路・ため池・堰・用水群・揚水機場など）。農水省の対象施設区分に合わせた。
whis:waterSource文字列またはWikidata水源の川・湖など。Wikidata の QID が分かるときは IRI で示す。
whis:prefectureCode文字列都道府県コード（ISO 3166-2:JP 形式、例: JP-04）。
whis:irrigatedAreaxsd:decimalかんがい面積（ha）。資料によって値が異なるものは空欄にし、comment に両方を書いた。
whis:managedBy文字列管理者（土地改良区など）。
whis:representativePoint文字列座標を取った代表地点の名前（取水口・堰・池など）。
